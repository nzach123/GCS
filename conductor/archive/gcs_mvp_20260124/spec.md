# Specification: GCS Landing Page MVP

## Goal
Build a single-page, static landing page for the Game Creator Space that drives Discord joins and club attendance.

## Requirements
1. **Visuals:** Match the reference design (Diagonal split, Bebas Neue headers).
2. **Sections:** Hero, Why/Features, Events/Meeting Info, Join/Footer.
3. **Tech:** HTML5, CSS3, Google Fonts. No frameworks.
4. **Responsive:** Stack layout on mobile.
5. **Accessibility:** 4.5:1 contrast, visible focus states.
