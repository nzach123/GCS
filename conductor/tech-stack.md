# Technology Stack - Game Creator Space (GCS)

## Core Technologies
- **Markup:** HTML5
  - *Rationale:* Universal standard, no build step required, beginner-friendly for future club maintainers.
- **Styling:** CSS3
  - *Rationale:* Capable of all visual requirements (layout, typography, responsiveness) without the overhead of frameworks.
- **Scripting:** Vanilla JavaScript (Optional)
  - *Rationale:* Only for lightweight interactions (e.g., mobile menu toggles) if strictly necessary.

## Design Assets & Dependencies
- **Typography:** Google Fonts
  - *Headlines:* "Bebas Neue"
  - *Body:* "Barlow"
- **Hosting:** Static Hosting (e.g., GitHub Pages)
  - *Rationale:* Zero cost, high reliability, easy deployment.

## Constraints
- **No Build Tools:** No Webpack, Vite, or npm scripts.
- **No Frameworks:** No React, Vue, Bootstrap, or Tailwind.
- **Single File Structure:** Keep critical assets (CSS/JS) consolidated where possible for simplicity.
