# AI Onboarding — GCS

This folder contains guardrails and documentation for AI assistants working on this codebase.

## Quick Start for AI

1. Read [ai-brief.md](ai-brief.md) — Project context and AI role
2. Read [constraints.md](constraints.md) — What you cannot do
3. Reference other docs as needed

## Documents

| File | Purpose |
|------|---------|
| [ai-brief.md](ai-brief.md) | Project summary, goals, AI role definition |
| [architecture.md](architecture.md) | File structure, rendering strategy, data flow |
| [coding-standards.md](coding-standards.md) | HTML, CSS, JS conventions and patterns |
| [stack-decisions.md](stack-decisions.md) | Confirmed technologies, rejected alternatives |
| [constraints.md](constraints.md) | Hard limits, change control policies |
| [task-templates.md](task-templates.md) | Copy-paste templates for common tasks |
| [review-checklist.md](review-checklist.md) | Pre-commit verification checklist |

## Key Rules

1. No frameworks (React, Vue, etc.)
2. No build tools (npm, webpack, etc.)
3. Static HTML/CSS/JS only
4. Ask before changing structure, dependencies, or external links

## For Humans

These documents help AI assistants understand project constraints. Review them when onboarding new contributors or updating project direction.
