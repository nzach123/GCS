# AI Brief — Game Creator Space (GCS)

## Project Summary

A static landing page for a college game development club. Primary purpose: drive Discord joins and promote weekly in-person meetings.

## Core Facts

| Attribute | Value |
|-----------|-------|
| Product Type | Static landing page |
| Target Users | Freshman college students |
| Primary CTA | Join Discord |
| Secondary CTA | Attend weekly meeting (MON 12pm, WB314) |
| Hosting | GitHub Pages |
| Maintainers | Club members (beginner to intermediate skill) |

## Success Criteria

1. Visitors click the Discord link
2. Visitors show up to in-person meetings
3. Site loads fast (<1s FCP)
4. Code is simple enough for any club member to edit

## What This Is NOT

- Not a web app (no auth, no state, no backend)
- Not a CMS-driven site (content lives in HTML)
- Not a marketing site (no lead capture beyond Discord)
- Not a portfolio (no project showcase in MVP)

## AI Role

AI assists with:
- Writing and editing HTML/CSS/JS
- Explaining code to maintainers
- Suggesting improvements within constraints
- Debugging layout/styling issues

AI does NOT:
- Introduce frameworks, build tools, or dependencies
- Create features outside the defined scope
- Make architectural decisions without approval
- Modify the Discord invite link without confirmation

## Key Constraints

1. No JavaScript frameworks (React, Vue, etc.)
2. No build steps (no npm, no bundlers)
3. No external dependencies beyond Google Fonts
4. Must work on GitHub Pages as-is
5. Must remain editable by beginners
