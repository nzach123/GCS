## 🕹️ Game Engines

### Industry Standard
- **Unreal Engine** — AAA-grade engine with best-in-class visuals; great for 3D and cinematic-focused projects. [unrealengine.com](https://www.unrealengine.com) — *Free (royalty on commercial revenue)*
- **Unity** — Versatile 2D/3D engine with the largest tutorial ecosystem, ideal for most student projects. [unity.com](https://unity.com) — *Free (Personal plan) / Student Plan available*
- **Godot** — Lightweight, fully open-source engine with a beginner-friendly scripting language (GDScript). [godotengine.org](https://godotengine.org) — *Free & Open Source*

### Beginner Friendly
- **PICO-8** — A "fantasy console" that constrains you to simple tools, perfect for learning game logic fast. [lexaloffle.com/pico-8.php](https://www.lexaloffle.com/pico-8.php) — *Paid (one-time)*
- **GameMaker** — Drag-and-drop or code (GML) 2D engine, excellent for first-time devs. [gamemaker.io](https://gamemaker.io) — *Free tier / Student discounts*
- **RPG Maker** — Purpose-built for narrative-driven RPGs with minimal coding required. [rpgmakerweb.com](https://www.rpgmakerweb.com) — *Paid*
- **Construct 3** — No-code, browser-based 2D engine great for rapid prototyping. [construct.net](https://www.construct.net) — *Free tier / Paid subscription*

## Programming & Version Control

- **Visual Studio Code** — Lightweight, extensible code editor supporting virtually every language used in game dev. [code.visualstudio.com](https://code.visualstudio.com) — *Free*
- **JetBrains IDEs (Rider, CLion, etc.)** — Full-featured IDEs with powerful debugging, ideal for C#/Unity or C++ work. [jetbrains.com](https://www.jetbrains.com) — *Free via Student License*
- **Cursor** — AI-native code editor built on VS Code, useful for pair-programming with AI. [cursor.com](https://cursor.com) — *Free tier / Paid Pro*
- **GitHub** — Industry-standard version control and collaboration platform; unlocks free Pro tools via the Student Pack. [github.com](https://github.com) — *Free / Student Developer Pack*

## 3D Modeling & Animation

- **Blender** — Fully-featured, open-source 3D suite covering modeling, rigging, animation, and rendering. [blender.org](https://www.blender.org) — *Free & Open Source*
- **Maya** — Industry-standard for character animation and rigging in film/games studios. [autodesk.com/products/maya](https://www.autodesk.com/products/maya) — *Free via Student License*
- **ZBrush** — The go-to tool for high-detail digital sculpting of characters and organic assets. [pixologic.com](https://www.maxon.net/en/zbrush) — *Paid / Student pricing*
- **Cascadeur** — Physics-assisted animation software that speeds up realistic keyframe animation. [cascadeur.com](https://cascadeur.com) — *Free tier / Paid*
- **TrenchBroom** — Lightweight level editor built for classic Quake/Half-Life-style FPS level design. [trenchbroom.github.io](https://trenchbroom.github.io) — *Free & Open Source*

**AI-Assisted 3D Modeling**
- **Tripo** — Generates 3D models from text or image prompts, useful for rapid prototyping. [tripo3d.ai](https://www.tripo3d.ai) — *Free tier / Paid*
- **Meshy** — AI text/image-to-3D generator with texturing support. [meshy.ai](https://www.meshy.ai) — *Free tier / Paid*

## Texturing

- **Substance Painter** — Industry-standard PBR texture painting tool used across AAA studios. [adobe.com/products/substance3d-painter](https://www.adobe.com/products/substance3d/apps/painter.html) — *Free via Student License*
- **Quixel Mixer** — Free texture-blending tool built around the Megascans library. [quixel.com/mixer](https://quixel.com/mixer) — *Free*
- **ArmorPaint** — Open-source alternative to Substance Painter for PBR texturing. [armorpaint.org](https://armorpaint.org) — *Free & Open Source*

## 2D Art & Concept

- **Photoshop** — Industry-standard raster editor for concept art and UI mockups. [adobe.com/products/photoshop](https://www.adobe.com/products/photoshop.html) — *Free via Student License*
- **Krita** — Free, open-source painting software built specifically for digital artists. [krita.org](https://krita.org) — *Free & Open Source*
- **Aseprite** — The standard tool for pixel art and sprite animation. [aseprite.org](https://www.aseprite.org) — *Paid (or free if self-compiled)*
- **Inkscape** — Free, open-source vector graphics editor, great for UI and logo work. [inkscape.org](https://inkscape.org) — *Free & Open Source*
- **Affinity Designer/Photo** — One-time-purchase alternative to the Adobe suite for illustration and photo editing. [affinity.serif.com](https://affinity.serif.com) — *Paid (one-time)*
- **Tiled** — General-purpose 2D tile map editor supporting most engines. [mapeditor.org](https://www.mapeditor.org) — *Free & Open Source*
- **LDtk** — Modern, artist-friendly level design tool built as a successor to Tiled. [ldtk.io](https://ldtk.io) — *Free & Open Source*
