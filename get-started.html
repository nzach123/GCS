Game Engines

Pick the right engine for your game mechanics

Industry Standard

  • Unreal Engine AAA-grade engine with best-in-class visuals; great for 3D and cinematic-focused projects. Free (royalty on commercial revenue)
  • Unity Versatile 2D/3D engine with the largest tutorial ecosystem, ideal for most student projects. Free (Personal plan) / Student Plan available
  • Godot Lightweight, fully open-source engine with a beginner-friendly scripting language (GDScript). Free & Open Source

Beginner Friendly

  • PICO-8 A "fantasy console" that constrains you to simple tools, perfect for learning game logic fast. Paid (one-time)
  • GameMaker Drag-and-drop or code (GML) 2D engine, excellent for first-time devs. Free tier / Student discounts
  • RPG Maker Purpose-built for narrative-driven RPGs with minimal coding required. Paid
  • Construct 3 No-code, browser-based 2D engine great for rapid prototyping. Free tier / Paid subscription

Programming & Version Control

Write & Track Your Code

  • Visual Studio Code Lightweight, extensible code editor supporting virtually every language used in game dev. Free
  • JetBrains IDEs (Rider, CLion, etc.) Full-featured IDEs with powerful debugging, ideal for C#/Unity or C++ work. Free via Student License
  • Cursor AI-native code editor built on VS Code, useful for pair-programming with AI. Free tier / Paid Pro
  • GitHub Industry-standard version control and collaboration platform; unlocks free Pro tools via the Student Pack. Free / Student Developer Pack

3D Modeling & Animation

Build Your World

  • Blender Fully-featured, open-source 3D suite covering modeling, rigging, animation, and rendering. Free & Open Source
  • Maya Industry-standard for character animation and rigging in film/games studios. Free via Student License
  • ZBrush The go-to tool for high-detail digital sculpting of characters and organic assets. Paid / Student pricing
  • Cascadeur Physics-assisted animation software that speeds up realistic keyframe animation. Free tier / Paid
  • TrenchBroom Lightweight level editor built for classic Quake/Half-Life-style FPS level design. Free & Open Source

AI-Assisted 3D Modeling

  • Tripo Generates 3D models from text or image prompts, useful for rapid prototyping. Free tier / Paid
  • Meshy AI text/image-to-3D generator with texturing support. Free tier / Paid

Texturing

Surface Your Assets

  • Substance Painter Industry-standard PBR texture painting tool used across AAA studios. Free via Student License
  • Quixel Mixer Free texture-blending tool built around the Megascans library. Free
  • ArmorPaint Open-source alternative to Substance Painter for PBR texturing. Free & Open Source

2D Art & Concept

Sketch, Paint, Design

  • Photoshop Industry-standard raster editor for concept art and UI mockups. Free via Student License
  • Krita Free, open-source painting software built specifically for digital artists. Free & Open Source
  • Aseprite The standard tool for pixel art and sprite animation. Paid (or free if self-compiled)
  • Inkscape Free, open-source vector graphics editor, great for UI and logo work. Free & Open Source
  • Affinity Designer/Photo One-time-purchase alternative to the Adobe suite for illustration and photo editing. Paid (one-time)
  • Tiled General-purpose 2D tile map editor supporting most engines. Free & Open Source
  • LDtk Modern, artist-friendly level design tool built as a successor to Tiled. Free & Open Source

Audio

Sound Design & Music

  • Audacity Free, open-source audio recording and editing software. Free & Open Source
  • LMMS Free digital audio workstation for composing and producing music/SFX. Free & Open Source
  • FMOD Adaptive audio middleware for implementing dynamic music and sound in-engine. Free for students/indies
  • Wwise Industry-standard interactive audio engine used across AAA titles. Free non-commercial license

Productivity & Project Management

Stay Organized

  • Notion All-in-one workspace for GDDs, wikis, and task tracking. Free Student Plan
  • Trello Simple Kanban-style board for sprint and task management. Free
  • Figma Collaborative interface design tool, useful for UI/UX mockups. Free Student Plan
  • Excalidraw Minimalist whiteboarding tool for quick diagrams and flowcharts. Free
  • Discord The club's home base for communication, voice chat during work sessions, and community feedback. Free

Free Asset Libraries

Ready-to-Use Resources

  • Kenney Massive library of free, CC0-licensed 2D/3D game assets. Free
  • Poly Haven High-quality, free HDRIs, textures, and 3D models. Free & Open Source
  • Freesound.org Community-driven library of free sound effects and samples. Free
  • itch.io Marketplace and hosting platform for indie/student game releases and free asset packs. Free / Pay-what-you-want
  • Mixamo Free auto-rigging and motion-capture animation library for characters. Free
  • Quaternius Free low-poly 3D model packs, great for stylized prototypes. Free
  • Sketchfab Browsable library of downloadable 3D models (filter by CC license). Free tier / Paid
